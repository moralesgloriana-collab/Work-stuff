01 · Core pattern

Every name has three parts

Underscores separate the parts. Hyphens join the words inside a part. Hover or click a part to see what it carries.

__

Prefix

What the item is. btn_ button, txt_ text frame, anim_ animation, p_ paragraph style.

Descriptor

What it does or shows, by meaning not position. nav-next, hero-team, faq-answer-03.

Variant

Where it is or which one. Page p12, section sec-faq, order 01, language es.

01 · Core rules

Eight rules that apply everywhere

01lowercase for objects, styles, buttons, animations. UPPERCASE only for layers.
02Only a–z 0–9 _ -. No spaces, accents (ñ, á) or & / # . ( ).
03Start with a letter. Numbered layers are the only exception.
04Zero-pad numbers: 01…10. Pages p01, spreads s01.
05Describe meaning, not position: img_hero-team, not img_top-left.
06No temporary words: final, new, copy, test, names.
07Language last on multilingual jobs: _en, _es.
08Under 30 characters. The Layers panel truncates.
Why so strict? InDesign turns object and style names into IDs and CSS classes on EPUB, HTML and interactive-PDF export. Spaces and symbols break them.

02 · Layer structure

Copy, images and interactions each get a layer

Every document uses the same layer set, front to back (shown here with a second language). Click a layer to see what belongs on it.

Layers≡
Interactions on top: InDesign only registers clicks on the topmost object. Steps of 10 leave room to insert layers like 35_COPY-LEGAL.

06 · Animations

Animated content keeps its name and its layer

Add _animNN to the content name. NN is the Timing panel row; same number means play together. Only motion-only objects get anim_ and the 20_ANIMATION layer.

Test: would the object be pointless without its animation? Then it's motion-only.

Don't group across layers to animate together; give items the same NN. Animations don't play in interactive PDF.

Don't
  • Leave local overrides (the + next to a style)
  • Use [Basic Paragraph] on live text
  • Keep duplicates like Body 2
  • Hand off unused styles or swatches
Do
  • Keep the master set in _styles-master.indd or a CC Library
  • Load it into every new document
  • Choose “Use Incoming Definition” on conflicts
  • Set language once, in p_base
